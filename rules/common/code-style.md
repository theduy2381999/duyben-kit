# General code style

- Read the surrounding code before writing; follow the project's existing naming, structure and libraries.
- Prefer modifying or reusing existing functions over writing new ones.
- A function does one thing; variable and function names state their purpose, no cryptic abbreviations.
- Do not leave dead code, debug `console.log`/`print` calls, or TODOs without context.
- Comments explain **why**, not restate **what** the code does.
- Do not add new dependencies without asking the user.
