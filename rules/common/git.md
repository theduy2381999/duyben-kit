# Git

- Commit messages follow Conventional Commits: `type(scope): description`.
- Each commit holds one meaningful change; do not bundle unrelated work.
- Never commit files containing secrets (`.env`, keys, tokens, credentials).
- Never `push --force` to `main`/`master`; never push without the user's approval.
- Work on a separate branch for new features, named like `feat/...`, `fix/...`.
