# Python

- Follow PEP 8; add type hints to parameters and return values of public functions.
- Use `pathlib` instead of `os.path`; f-strings instead of `%` or `.format()`.
- No bare `except:`; catch the specific exception you handle.
- Use `logging` instead of `print` in production code.
- Write tests with `pytest`.
